# ML Projects: Classification & Regression

This repository contains two beginner-friendly machine learning projects demonstrating basic classification and regression workflows using Python and Jupyter Notebooks.

## 📁 Projects

### 1. 📧 Email Spam Prediction (Classification)
- **Goal**: Classify emails as spam or not spam.
- **Tech stack**: `sklearn`, `pandas`, `numpy`, `matplotlib`
- **Key steps**:
  - Data preprocessing
  - TF-IDF vectorization
  - Logistic Regression
  - Evaluation metrics (accuracy, confusion matrix)

### 2. 🚗 Car Price Prediction (Regression)
- **Goal**: Predict car prices based on features like mileage, brand, etc.
- **Tech stack**: `pandas`, `seaborn`, `sklearn`, `linear_model`
- **Key steps**:
  - Feature selection & encoding
  - Linear regression model training
  - Visualization of results
